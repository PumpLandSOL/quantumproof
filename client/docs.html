What is LATTICE

LATTICE is a layer-1 blockchain where no elliptic-curve cryptography is used anywhere. Blocks, validator attestations and user transactions are all signed with ML-DSA, the lattice-based digital signature standard NIST published as FIPS 204 in August 2024. Hashing is SHA3-256.

The testnet (lattice-testnet-1) is live: blocks every 4 seconds, a public explorer, a browser wallet and a faucet.

Why quantum resistance

Bitcoin and Ethereum sign with ECDSA/Schnorr over secp256k1; Solana and NEAR use Ed25519. All of them rest on the elliptic-curve discrete-log problem, which Shor's algorithm solves efficiently on a large fault-tolerant quantum computer. Once a public key is visible on-chain, such a machine could derive the private key.

Signed data recorded today stays on-chain forever, so the risk is "harvest now, break later". Moving to post-quantum signatures has to happen before that hardware exists.

ML-DSA's security rests on the Module-LWE and Module-SIS lattice problems, for which no efficient quantum algorithm is known. Node signatures use the platform's native FIPS 204 implementation; browser wallets use the audited open-source @noble/post-quantum library. Both produce standard-encoded keys and signatures, so a wallet signature is verified natively by the node.

Consensus

Four validators (Kyber, Dilithium, Falcon, Sphincs) each hold an ML-DSA-65 key. Proposers rotate round-robin each 4-second slot.

header = { height, prev, time, txRoot, proposer, txCount }
hash   = SHA3-256(canonical(header))
block  = header + ML-DSA-65 proposer sig + attestations
final  ⇔ proposer sig valid AND ≥ 2 of 3 attestations valid

Every signature is verified before the block is appended; a block that fails is dropped and its transactions return to the mempool. Fees go to the block's proposer.

Transactions

body = canonical({ amount, chain:"lattice-testnet-1", fee, from, nonce, to })
sig  = ML-DSA-44.sign(sk, body)
tx   = body + pub (1,312 B) + sig (2,420 B)
  • The node checks that SHA3-256(pub) matches the from address, then verifies the signature against the body.
  • The nonce must equal the account's next nonce, which stops replays.
  • The chain field binds the signature to this network.
  • Network fee: 0.001 tLATT.

Wallet

The wallet at /wallet generates a 32-byte random seed with the browser's secure RNG and derives an ML-DSA-44 keypair from it. The seed is stored only in this browser; back it up with Reveal seed. Addresses look like:

lat1 + first 20 bytes of SHA3-256(public key)  →  lat1c0ffee…

The faucet credits 1,000 tLATT per address per hour.

$LATT

$LATT is the LATTICE community token, launched on pump.fun (Solana). The contract address is shown on the front page with a copy button. tLATT is the testnet gas asset; it is separate from $LATT.

FAQ

Is quantum resistance real or marketing?

Real. ML-DSA is a published NIST standard and every signature on this network is one. Open any block in the explorer to see the full ML-DSA-65 signatures and their byte sizes.

Why are signatures so much bigger?

Lattice signatures trade size for quantum security: 2,420 bytes versus 64 for Ed25519. LATTICE is designed around that size from the start.

Does the server ever see my key?

No. Keys are generated and used in your browser. The node only receives your public key and signature.

Is this mainnet?

No. This is lattice-testnet-1; tLATT has no monetary value.

Why ML-DSA and not SPHINCS+ or Falcon?

ML-DSA is NIST's primary general-purpose signature standard, with fast signing and verification. SLH-DSA (SPHINCS+) signatures are larger and slower; Falcon needs delicate floating-point sampling.
